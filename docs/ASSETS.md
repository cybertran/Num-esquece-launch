Os desenhos de sino presentes em:

- `app/src/main/res/drawable/ic_notification.xml`
- `app/src/main/res/drawable/ic_launcher_foreground.xml`

são baseados no conjunto Google Material Icons. Material Icons é distribuído pelo Google sob Apache License 2.0. O arquivo completo da licença está em `LICENSES/Apache-2.0.txt`.

O launcher contém adaptações visuais próprias do projeto sobre essa base. As alterações específicas do projeto são distribuídas sob GPL-3.0-or-later, sem alterar os termos aplicáveis ao material de origem Apache-2.0.

Os arquivos de adaptive icon em `mipmap-anydpi-v26` apenas referenciam os recursos acima.
